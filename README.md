# Hi, I'm Talha 👋

## How I Work

- Focus on correct behavior before optimization
- Prefer explicit, maintainable code over unnecessary abstractions
- Debug systematically, paying attention to memory, timing, and state flow
- Build and test systems at the hardware level
- Prioritize reliability, fault handling, and predictable system behavior

I'm interested in understanding how complete systems work, from hardware and low-level firmware to communication protocols and backend integration.
